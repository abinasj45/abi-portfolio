# Abinas J — Portfolio

React 18 + Vite + GSAP (ScrollTrigger).

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
npm run preview
```

- Content lives in `src/data.js` — edit text there.
- Animations live in `src/useAnimations.js`.
- Styles (light/dark follow the system) live in `src/index.css`.
- Deploy: push to GitHub and import into Vercel/Netlify (build: `npm run build`, output: `dist`).
